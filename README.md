# JavaScript Basics: Transaction Calculator

A small JavaScript exercise focused on functions, parameters, arithmetic operations, and template literals.

## What it does

The `makeTransaction(quantity, pricePerDroid)` function calculates the total cost of a droid order and returns a formatted confirmation message.

## Concepts practiced

- Declaring functions and parameters
- Multiplication and variable assignment
- Returning values from functions
- Template literals
- Calling functions with different arguments

## Run locally

Open `index.html` in a browser and check the output in the developer console.

## Project context

This is an introductory GoIT JavaScript homework exercise. It is intentionally small and focuses on the fundamentals rather than a complete user interface.
